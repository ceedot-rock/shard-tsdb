# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest minor release | Yes |
| Older minors | Best effort |

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Instead:

1. Use GitHub's private vulnerability reporting on this repo, or
2. Email corey@slidphilabs.com with `SECURITY: shard-tsdb` in the subject.

Include: affected version or commit, steps to reproduce, and impact. You
will get a first response within 5 business days. Do not disclose the issue
publicly until a fix is released. Good-faith reporters are credited in the
release notes unless they ask otherwise.
